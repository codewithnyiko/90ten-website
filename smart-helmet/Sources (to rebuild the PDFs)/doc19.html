Smart Helmet: Updated Questions

What we still need to know now that we understand what the helmet does.

Prepared for Thella Group Services and Imperium Corporate Designed and prepared by 90Ten Group 20 October 2026 v1.00

What we now understand

The helmet asks an address server where to report and then keeps a live link open to the server it is given. It sends a report every 10 seconds with its position and battery and the Bluetooth devices it hears. It sends alarms at once. We can send it commands and settings. The supplier's Interface Document describes all of this and it is enough to build version v1.00. The document also says the messages differ between software versions.

No longer asked

Whether the helmet can report to the client's server (yes, in two ways). Whether there is a written list of messages (yes, the Interface Document). Whether it can warn about beacon areas (yes, alarm types 17 and 18). Whether the server can set Wi-Fi (yes, on camera models).

To build and test v1.00

No.QuestionWhy we ask
A1Imperium has two helmets in South Africa. When can we use one to build and test? Please confirm the model and that it is a high-end camera model and give us its admin login on the supplier platform.We need a helmet in hand to build and test. The address change and the Wi-Fi commands work only on camera models.
A2The document says messages differ between software versions. Which versions exist and how do the messages differ? Which version are the two helmets in South Africa on?This is critical. If a message changes between versions our software must handle both.
A3Does the helmet need the supplier address server every time it starts? Does it remember the last addresses if that server cannot be reached?If the helmet forgets them, a problem on the supplier side stops the helmets from reporting.
A4After we change the addresses, does the helmet still call the supplier for anything else, such as update checks or the voice package?The client wants its data to stay in South Africa.
A5Does the helmet accept secure addresses (https and wss) or only plain http and ws?The examples use plain addresses. Worker positions should travel securely.
A6Are positions in South Africa normal GPS positions or shifted by the Gaode system?A shifted position puts a worker in the wrong place on a normal map.
A7Can a helmet setting change while it is on or only at start-up? What should we send in sip_info while we have no call server?The settings arrive at start-up. The login reply cannot leave sip_info empty.
